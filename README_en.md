# sing-box for KernelSU

A local configuration panel rendered inside KernelSU Manager. The panel uses the KernelSU shell bridge; no browser dashboard is served. The management API listens only on `127.0.0.1:9090`.

See [README.md](README.md) for installation, features, configuration and validation details. Upgrade packages use the existing `box4` module id and preserve personal nodes and app bypass settings. Distributed configurations contain sample nodes only.
